# ベイクパーセント

パン・お菓子づくりのための、ベーカーズパーセント計算ツールです。小麦粉を100%とした比率で
配合を組み立て、作りたい量へスケールし、目標の生地温度から仕込み水温を逆算し、生地温度ごとの
発酵時間の目安までを一画面で扱えます。すべてこの端末の中だけで計算し、サーバーには何も送りません。

## 誰の何を解決するか

レシピを2倍・半量にするたびに全材料をかけ直したり、レシピ本の「28℃で60分」という一律の発酵指示が
自宅の気温では合わなかったりする——そんな手計算と勘の部分を、計算で解ける範囲だけ正直に肩代わりします。
家庭〜セミプロのつくり手が、粉の量・作りたい生地量・その日の室温に合わせて配合と段取りを決められます。

## 使い方

1. **配合（ベーカーズ％）**: 小麦粉は100%固定の基準です。水・塩・酵母などを追加し、それぞれの
   対粉比（％）を入れます。粉の重さ(g)を入れると各材料の重さが自動で出ます。重さ側を入力すると
   ％を逆算します。各行の横筋（reach bar）が粉100%を基準にした比率を表します。
2. **バッチスケール**: 「粉量から」「総生地量から」「倍率で」のいずれかで、作りたい量にスケールします。
   ％は変わらず、重さ(g)だけが伸縮します。
3. **仕込み水温（DDT）**: 目標の生地温度・室温・粉温・こね方の摩擦係数（プリセットあり）を入れると、
   仕込み水温を逆算します。中種／ルヴァンを使う場合はその温度も加味します。
4. **発酵時間の目安**: 「この温度で何分」という基準を1つ入れると、生地温度ごとの発酵時間の目安を
   カーブと表で示します。スライダーで生地温度を動かすと目安時間が変わります。

配合は自動でこのブラウザに保存され、次に開いたときに復元されます。

## できないこと（制限事項）

- 発酵時間はあくまで目安です。酵母の種類・量、粉や配合、こね上げ後の扱いで実際は変わります。
  入力した基準点からの外挿であり、正確な時間を保証するものではありません。
- 仕込み水温は摩擦係数の目安に依存します。実際のこね上がり温度を測って係数を調整すると精度が上がります。
- オーブンの焼成温度・時間や、栄養計算は扱いません。

## 開発

Next.js (App Router)。`out/` への static export で配信するためサーバランタイムは不要。

```bash
./setup.sh                 # 依存の導入
pnpm dev                   # http://localhost:3000（ホットリロード）
```

## ビルド

```bash
pnpm build                 # next build → out/ に静的 HTML/CSS/JS を生成
```

`out/` がそのまま配信物。

## テスト

```bash
pnpm test                  # node --test（計算コア lib/baking.mjs のユニットテスト）
```
